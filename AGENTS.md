# Year of Ice: start here (any AI agent)

Year of Ice is a first-person Alaskan survival game built as a NeoForge mod for Minecraft Java 1.21.1 (Java 21, GeckoLib 4.9.3, Curios 9.5.1). It is a personal project for Ruhan, based on Forge Labs' "1 Year in Alaska". There are no hostile mobs: cold, hunger, weather and wildlife are the game.

This file is the handoff. Read it, then `CLAUDE.md` (the code rules), then only what your task needs.

## Build, test, ship

```
./gradlew build                                     # compile + 680+ JUnit tests
tools/gametest.sh -Pgametest.filter=<prefix>/       # GameTests for your area (eco/, hunt/, fire/, build/, garden/ ...)
tools/prepush.sh                                    # ignored-file check, id inventory, lint, build
```

- `main` always passes. Work on a branch `dev/<department>/<topic>`, open a pull request, let CI (the full GameTest suite) go green, then squash-merge.
- Never run `runServer` and never accept the Minecraft EULA in automation; use the GameTest server.
- New ids go through `tools/newid.sh`; never hand-edit `studio/inventory.json`.
- Art is generated by scripts in `tools/artgen/` from `tools/artgen/palette.json` (max 3 ramps per 16x16 icon); every asset needs an entry in `assets/yearofice/credits.json`.
- A client smoke run (`YEAROFICE_SMOKE=<name> ./gradlew runClient` under Xvfb) drives the game like a player and writes `run/smoke/<name>.log`. Drivers live in `com.yearofice.client.smoke`.
- Before a squash: `git fetch`, merge `origin/main` into your branch, then squash. A squash from a stale tree silently reverts other people's work (it happened twice).
- Memory: a GameTest JVM needs about 2 GB and a client about 2 GB. Exit code 137 is an out-of-memory kill, not a test failure. Do not run a full build beside a client run.
